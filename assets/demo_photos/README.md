## 1. 诚实声明（**先读这一段**）

用户原始需求是「女生拍照」主题 —— 自拍 / 他拍人像 / 生活打卡 /
旅行留念 / 咖啡馆 / 街拍。

**但本素材库无法完全满足该需求**，原因经实测确认：

1. **可用图源没有主题检索能力。**
   `Pexels` / `Unsplash` 搜索 API 返回 **401（需申请 Key）**；
   `Wikimedia` / `Openverse` **网络不可达**。
   唯一可用的 `Picsum` 是**随机摄影图库，不提供任何主题标签**，
   因此**无法检索"咖啡馆""街拍"**。

2. **图库总量仅 993 张，无法扩大。**
   实测分页在第 11 页结束。这不是分页限制，是图库真实规模。

3. **人像占比极低。**
   993 张中仅 **34 张（3.4%）**能检出人脸，最终可用 **14 张（1.4%）**。

4. **自动检测会误判，必须人工复核。**
   19 张自动通过筛选的图中，**5 张（26%）实际不可用** ——
   包括**不是人像的静物**（一串葡萄、办公桌、室内空间）、
   运动模糊、只拍到腿部、男性背影等。

5. **AI 人脸源的构图多样性为零。**
   `thispersondoesnotexist` 输出**恒为正面免冠照**，
   与本项目「构图指导」的核心价值冲突，因此**单独存放、明确用途边界**。

**因此本素材库采取的策略是：**

- 目录名只用**数据源可验证的客观属性**（景别 / 人脸朝向 / 主体数 /
  构图分），每个目录名与内容严格对应，**不存在"目录名说咖啡馆、
  实际是雪山"的造假**。
- 场景主题（自拍 / 咖啡馆 / 街拍）另出 [`curated/review_manifest.json`]
  与 [`topics.json`]，并**显式标注为人工目视判断、可信度有限**。
- 剔除的素材**保留在 `_rejected_with_reason/` 而非删除**，
  连同理由一起存档，供第三方复核对。

## 2. 目录结构

```
assets/demo_photos/
├── README.md                       # 本文件
├── _index.json                     # 原始池索引（19 张，含全部实测字段）
├── _index_by_attribute.json        # 按属性归档后的索引
├── topics.json                     # 场景主题清单（**人工作业，含可信度声明**）
├── PROVENANCE.md                   # 逐图作者 / 原始页 / 授权
├── *.jpg                           # 原始池平铺（19 张）
│
├── by_attribute/                   # 【未筛选】按实测景别归档
│   ├── big_closeup/  half_body/  full_body/  distant/
│
├── curated/                        # 【人工复核后】推荐使用这一层
│   ├── review_manifest.json        # 复核清单：保留/剔除 + 逐张理由
│   ├── by_attribute/               # 14 张保留素材（按实测景别）
│   │   ├── big_closeup/  8 张
│   │   ├── full_body/    5 张
│   │   └── distant/      1 张
│   └── _rejected_with_reason/      # 5 张剔除素材（**保留证据，不删**）
│
└── faces/                          # 【独立用途】AI 生成人脸 20 张
    ├── _index.json
    └── faces_NN_ai_generated_1024.jpg
```

**使用建议**：做演示/评测请用 `curated/by_attribute/`，
不要直接用 `by_attribute/`（后者含未剔除的假阳性）。

## 3. 命名规范

真实照片（文件名即属性摘要，便于检索与核对）：

```
{序号}_{景别}_{人脸朝向}_{检出主体数}p_{构图分×100}.jpg
```

例：`01_big_closeup_frontal_3p_7417.jpg`

| 字段 | 含义 | 取值 |
| --- | --- | --- |
| 序号 | 入库顺序 | `01`~`19` |
| 景别 | **实测**主体占比分档 | `big_closeup`(≥25%) / `half_body`(10~25%) / `full_body`(3~10%) / `distant`(<3%) |
| 人脸朝向 | **实测** | `frontal`(正脸) / `profile`(侧脸) |
| 主体数 | **实测** YOLO 检出人数 | `1p`~`8p` |
| 构图分 | **实测**本项目评分器输出 | `0000`~`9999`（×100） |

AI 人脸：
```
faces_{序号}_ai_generated_1024.jpg
```

全部 ASCII + 下划线，规避 Windows 非 ASCII 路径的 OpenCV 读取问题
（`cv2.imread` 在中文路径上静默返回 `None`，必须用 `np.fromfile` 兜底）。

## 4. 场景主题：**人工作业，可信度有限**

`topics.json` 中的 `scene_topic` 字段是**人工/规则推断**，
**不是数据源标签**（图源根本没有主题元数据）。

推断规则（可解释、可复现）：

| 主题 | 触发条件 |
| --- | --- |
| `group` | 检出 ≥2 个人 |
| `selfie_like` | 正脸 + 人脸占画面 ≥3% + 主体占比 ≥25% |
| `portrait_posed` | 正脸 + 主体占比 ≥10% |
| `casual_lifestyle` | 单主体 + 主体占比 <10% |
| `outdoor_scene` | 平均亮度 ≥0.55 且主体占比 <25% |
| `unclassified` | 以上均不满足 —— **按诚实原则留空，不硬凑** |

每张图的 `topic_basis` 字段记录了**具体依据**，
`topic_confidence` 标注可信度（`medium` / `low`）。

**使用者须知**：这些标签**可能存在误判**，仅用于素材挑选时的粗略索引。
客观属性请直接看文件名或 `_index.json`。

- 图片经由 [Picsum](https://picsum.photos/) 分发，原始来源为 Unsplash。
- 适用 [Unsplash License](https://unsplash.com/license)：
  免费用于商业与非商业用途，**无需署名**；
  **禁止**将未修改的图片汇编为竞品图库二次分发。
- 逐图 `author` 与 Unsplash 原始页地址已记录在 `_index.json` 与
  `PROVENANCE.md`，可溯源。
- **合规复核**：已逐张目视确认无低俗、敏感内容。

### 5.2 AI 人脸素材（20 张）

- 来源 `thispersondoesnotexist.com`，**生成式人脸，无真实人物肖像权问题**。
- ⚠️ 该源**未提供明确授权条款**，因此：
  - 仅在**内部验证**用途下使用；
  - 若用于公开演示，**必须注明为 AI 生成**；
  - 不用于任何声称"真实用户素材"的场景。

## 6. 用途边界（**重要**）

| 用途 | 可用素材 | 说明 |
| --- | --- | --- |
| **构图指导演示** | `curated/by_attribute/` 14 张 | 有景别梯度（大特写→远景）、主体数梯度（1p→8p）、构图分跨度（44~74） |
| 感知层检测链路验证 | `faces/` 20 张 | 人脸密集、质量高、年龄/性别/族裔多样 |
| **构图恒定对照组** | `faces/` 20 张 | 同一构图不同人脸 → 评分应几乎不变，**反证评分器对构图敏感** |
| ❌ 主题化展示（咖啡馆/街拍） | 无 | 图源无主题检索能力，**做不到** |
| ❌ 大规模评测集 | 无 | 见图源天花板 993 张 |

## 7. 复现方式

```bash
# 1) 采集真实照片并自动筛选（约 3 分钟）
python scripts/fetch_demo_photos.py --target 20 --min-sharp 150 --min-comp 40

# 2) 按实测属性归档 + 生成主题清单
python scripts/organize_demo_assets.py

# 3) 生成人工复核拼图
python scripts/make_demo_sheet.py
#    -> outputs/reports/demo_photos_contact_sheet.png

# 4) 按人工复核清单整理出 curated/（复核结论已固化在脚本内）
python scripts/curate_demo_assets.py

# 5) 采集 AI 人脸（串行限速，约 160s / 20 张）
python scripts/fetch_face_samples.py --target 20 --delay 3
```

复核结论固化在 `scripts/curate_demo_assets.py` 的 `REVIEW` 字典中，
因此**复核过程本身是可复跑、可审计的**，而不只存在于某次对话里。
