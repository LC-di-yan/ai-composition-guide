## 2. 为什么走「Bing 检索 + 白名单直链」这条路

实测记录（详见 `docs/research/素材图源调研.md`）：

| 渠道 | 结果 |
|---|---|
| Pexels API | **401** 需 Key |
| Unsplash API | **401** 需 Key |
| Pexels / Unsplash 网页 | **403** Cloudflare「Just a moment...」 |
| Pixabay 网页 | **403** |
| Openverse API | **502** |
| Wikimedia | SSL EOF |
| Met Museum API | **200**，但只有博物馆藏品，非现代人像 |
| **Bing 图片 async 接口** | **200**，35 条结构化结果（`murl`/`purl`/`desc`） |
| **免费图库 CDN 直链** | **200**（网页被挡，图片本身可下载） |

结论：**网页打不开，不等于图片下不了**。用 Bing 做主题检索、再从结果里筛出
免费图库的 CDN 直链，是当前环境下唯一可持续的路径。

### 2.1 合规闸门是硬性的，不是可选项

不带白名单直接抓 Bing 结果时，**首轮 35 条里有 28 条来自付费图库**：

| 域名 | 命中 | 判定 |
|---|---|---|
| `img.freepik.com` | 266 | ❌ 付费 |
| `thumbs.dreamstime.com` | 132 | ❌ 付费 |
| `cdn.vecteezy.com` | 97 | ❌ 付费 |
| `c8.alamy.com` | 67 | ❌ 付费 |
| `images.stockcake.com` | 74 | ❌ 付费/未知 |
| `media.gettyimages.com` | 36 | ❌ 付费 |
| **`cdn.pixabay.com`** | **46** | ✅ 白名单 |
| `www.publicdomainpictures.net` | 7 | ✅ 白名单 |

因此 `FREE_HOSTS` 白名单**写在脚本里、不可通过参数关闭**。

## 4. 主题标签的性质（**重要，勿误读**）

`topic_requested` 字段**来自检索关键词，不是图库官方标签**。

也就是说：`street` 表示"它是用 street 相关关键词搜出来的"，**不等于**
"图库把它标注为街拍"。检索词与实际内容存在偏差，实测已抓到反例：

- `26_street_*.jpg` 用 `woman` 检索，结果主体是**戴眼镜的男性** → 已剔除；
- `09_outdoor_*.jpg` 检索 outdoor，结果是**无法辨认人物的礁石剪影** → 已剔除。

索引里每一条都保留 `note` 字段复述这一点。**任何基于 topic 的统计都要
带上这个前提**，不能当作权威分类。

## 5. 三道筛子的分工（为什么缺一不可）

| 环节 | 脚本 | 保证什么 | **保证不了什么** |
|---|---|---|---|
| 采集 | `fetch_topic_photos.py` | 域名合规、能解码、尺寸达标 | 画面里**有没有人**、**合不合适** |
| 人检 | `curate_topic_photos.py` | 有清晰可辨的女生、不低俗、构图可用 | 本项目检测器**能不能跑通** |
| 复筛 | `screen_topic_photos.py` | YOLO 能检出主体、面积比够、未降级 | 美感（机器判不了） |

**剔除率 23.3%（7/30）**，三类原因分布：

| 原因类型 | 张数 | 例子 |
|---|---|---|
| 主题误报（检索词与内容不符） | 2 | 男性主体、不可辨剪影 |
| 合规从严（低俗风险） | 1 | 露肤度较高的街拍 |
| 质量/冗余（糊、重复、分辨率不足） | 4 | 同源连拍、玻璃反光、分辨率过低 |

> **这批数据本身就是一个结论**：自动采集的**主题准确率只有 ~93%**
> （28/30 里 2 张主题错），**质量可用率 76.7%**。任何"爬了就入库"的做法
> 都会把这两类错误带进素材库。

## 6. 与既有素材库的关系

| 目录 | 内容 | 定位 |
|---|---|---|
| `assets/demo_photos/` | 19 张 Picsum 随机 + 20 张 AI 人脸 | **属性覆盖**：按景别 × 人脸朝向铺满网格 |
| `assets/topic_photos/` | 23 张主题检索素材 | **主题覆盖**：按六个真实拍摄场景组织 |

两者互补：前者保证**每种构图属性都有样本**，后者保证**每个使用场景都有画面**。
用户要求「属性目录 + 主题清单」两者都要，即指这两套并存。

## 7. 复现方式

```bash
python scripts/fetch_topic_photos.py --target 30 --pages 3   # 采集
python scripts/make_topic_sheet.py                            # 出总览拼图供目检
python scripts/curate_topic_photos.py                         # 应用人工裁定
python scripts/screen_topic_photos.py                         # 过本项目 YOLO 链路
```

> **可复现性说明**：Bing 检索结果会随时间和地域变化，**重跑不保证拿到
> 完全相同的图**。但 `_index.json` 记录了每张图的 `source_url` /
> `source_page` / `license`，**已入库的素材可逐张溯源**，不受重跑影响。
