# 启用方式（两条路径，二选一）：
#
#   A. 生产/容器路径 —— Milvus Standalone（docker-compose 里的服务）
#      pip install "pymilvus==2.6.17"
#      版本选取依据：Milvus 服务端 v2.6.24 的 Release Note 明确其 Python SDK
#      = 2.6.17，客户/端服务次版本对齐（2.6 vs 2.6）避免协议漂移。
#
#   B. 本机免 Docker 路径 —— Milvus Lite（单进程， Windows 实测可用）
#      pip install "pymilvus==2.6.17" "milvus-lite>=3.0,<3.3"
#      然后 AICG_RETRIEVAL_URI=<路径>/composition_cases.db
#      **诚实边界**：Milvus 官方支持矩阵仍只写 Linux/macOS，Windows 属

#        1) Milvus 客户端**首次初始化必须在帧处理链路之前**，否则 Lite 在
#           pa.RecordBatch 写入路径 SIGSEGV；代码侧用启动期预热规避；
#        2) Lite 落盘用 POSIX 语义的 os.rename，已存在同名文件时 Windows
#           抛 WinError 183 → 重建请换新的 .db 路径，不要依赖 drop。
